# AI 助手与 GitHub 同步

按你的要求，原本排在 v1.2 的 AI 和 v2 的 GitHub 同步提前做了。两项都已用本地模拟服务在模拟器上完整验证；**还没有接真实的模型和真实的 GitHub 仓库**，需要你填上配置后在真机上试。

## AI 助手（DESIGN §6）

**设置**：命令面板 →“AI 设置”，填写：
- 接口地址：OpenAI 兼容的 base_url，例如家里节点经 Tailscale 接入时 `http://100.x.x.x:11434/v1`（Ollama），或者 `https://api.openai.com/v1`
- API key：本地模型通常留空；填了会用 Android Keystore 加密保存在本机
- 模型：例如 `qwen2.5:14b`

填好后点“测试连接”。

**使用**：选中一段文字（不选就是光标所在的段落），按 `Ctrl+J`，选一条指令。结果在屏幕下方的面板里流式出现（每 0.5 秒刷新一次，避免墨水屏逐字闪烁）：
- `Enter`：默认动作（润色、精简等是替换原文，续写是插到后面）
- `Ctrl+Enter`：另一种动作
- `R` 重试，`Esc` 放弃。AI 不会直接改正文；替换前会核对原文没有变。替换后 `Ctrl+Z` 可以撤销。

**自定义指令**：命令面板 →“编辑 AI 指令”，打开 `Documents/momoda/prompts.md`：
```
## 指令名
要求……{{text}} 是要处理的文字，{{context}} 是光标前的上文。
模式：插入        ← 可选，表示结果插到后面
```

## GitHub 同步（DESIGN §5）

**登录（推荐，汉王上不用打字）**：命令面板 →“用 GitHub 登录（同步）”。屏幕上会显示一个 8 位验证码，在手机或电脑上打开 github.com/login/device 输入它并点 Authorize。授权后 App 自动选好仓库（只有一个时）并开始第一次同步。

这依赖一个公开的 GitHub App：**墨墨打同步 Momoda Sync**（slug `momoda-sync`，Client ID `Iv23liK9KsMUubPabWgP`，由 @zhixianio 维护，2026-10-20 注册）。任何用户都不需要自己注册：第一次登录时，如果还没把它安装到自己的仓库，App 会显示安装地址 `github.com/apps/momoda-sync/installations/new`，在手机或电脑上装好后自动继续。

- 权限：只有 Contents（读写）和 Metadata（只读），没有 webhook。
- 登录凭证只保存在用户自己的设备上，App 作者拿不到。我们没有为这个 App 生成过私钥（同步用不到它）；生成私钥的人可以访问所有安装了这个 App 的仓库，所以如果以后需要生成，要在 README 里公开说明。
- token 不过期（关闭了 user-to-server token expiration）：续期需要 client secret，开源 App 里不能放；用户可以随时在 GitHub → Settings → Applications 里撤销授权。

**备用：手动填 token**：命令面板 →“GitHub 同步设置”，填 `用户名/仓库名`、分支、fine-grained token（Contents: Read and write，只选这个仓库）。长文本可以用下面的“从手机或电脑粘贴”传过来。

同步仓库：[zhixianio/momoda-notes](https://github.com/zhixianio/momoda-notes)（私有，2026-10-20 创建）。

**使用**：`Ctrl+Shift+S` 或命令面板“立即同步”。自动同步默认开启：离开 App（距上次超过 2 分钟）和回到 App（超过 10 分钟）时各同步一次。页脚会显示“已同步 HH:mm”或“同步失败”。

**规则**（设备为准，任何一方都不丢）：

| 情况 | 结果 |
|---|---|
| 只有一边改了 | 另一边跟上 |
| 两边都改了同一篇 | 推送你的版本；远端版本另存为 `标题.remote-月日-时分.md` |
| 远端删了、你没改 | 本地移进回收站 |
| 你删了、远端没改 | 远端也删除 |
| 你删了、远端又改过 | 把远端版本拉回来 |

同步范围是 `Documents/momoda` 里所有 `.md` 文件，包括子目录（例如 agent 写的 `_agent/`），不包括字体和回收站。仓库根目录的 `README.md` 也会被同步下来，作为一篇普通文档。

**和 agent 协作**：按设计稿的约定，agent 只写 `_agent/` 目录（例如 `_agent/第一章.review.md`），正文以设备为准。目前 `_agent/` 里的文件会同步到本机，但还没有在 App 里并排查看的入口（设计稿里的 `Ctrl+Shift+A`），可以先用文件管理器看。

### 维护者：GitHub App 的配置（已完成，记录备查）

在 https://github.com/settings/apps/momoda-sync ：

## 从手机或电脑粘贴

命令面板 →“从手机或电脑粘贴”：汉王上显示一个局域网地址（例如 `192.168.1.120:8899`）和 4 位配对码。在同一 Wi-Fi 下的手机或电脑浏览器里打开这个地址，可以填：
- AI 设置（接口地址、API key、模型）
- GitHub 仓库和 token
- 一段正文：插入到当前文档的光标处

只填需要的部分即可。提交一次、配对码输错 5 次或 10 分钟没人使用后自动关闭；窗口打开期间保持 Wi-Fi 全速（汉王的 Wi-Fi 省电模式会让局域网请求时断时续）。局域网内是明文传输，只在自己信任的 Wi-Fi 下使用。

在汉王真机上验证过：错误配对码被拒绝，正确配对码把文字插入光标处，提交后服务关闭。

## 还没做 / 已知限制

- `_agent/` 文件的并排查看（`Ctrl+Shift+A`）
- 子目录里的文档不会出现在文档列表和管理页里（目前只列出顶层的文档）
- 同步大文件或很多文件时没有进度条，只在页脚显示“同步中”
- 国内访问 GitHub 和 api.github.com 可能不稳定（发布准备会话的 RELEASE.md 也提到了），失败会在页脚提示，下次自动重试
