## 性能（自查发现并修复）

| 问题 | 原因 | 结果 |
|---|---|---|
| 打开 4 万字文档时主线程卡死约 25 秒（模拟器） | Markdown 样式逐个挂在编辑器的文字上，每个 Span 都触发一次重新排版 | 改为先在副本上渲染好再一次性载入：模拟器上无掉帧；汉王上切换到该文档无掉帧 |
| 每次按键整篇扫描外来样式 | — | 只扫描变动范围 |
| 多音字搜不到（“长文”的 cw） | 拼音表只有一个读音 | 加入其他读音（kTGHZ2013、kXHC1983） |

**已知限制**：在汉王上冷启动直接进入 4 万字文档约 1.2 秒（打开和渲染约 250ms，首次排版约 600ms），超出“1 秒内可输入”的目标；普通长度（几千字）的文档约 0.3 秒。以后如果需要，可以考虑长文档分章节。

## 需要你确认 / 决定

- **检查更新还没有发布地址**：`app/build.gradle.kts` 里的 `UPDATE_API` 现在留空，所以功能是关闭的。等 GitHub 仓库建好后填上 `https://api.github.com/repos/<你的用户名>/momoda/releases/latest`。
- **正式签名**：现在的 release 包用的是 debug 密钥。换成正式密钥后，需要先卸载旧包再安装（签名不同，系统不允许直接覆盖）。卸载前文档都在 `Documents/momoda`，不会丢。
