## 需要你确认 / 决定

- **检查更新还没有发布地址**：`app/build.gradle.kts` 里的 `UPDATE_API` 现在留空，所以功能是关闭的。等 GitHub 仓库建好后填上 `https://api.github.com/repos/<你的用户名>/momoda/releases/latest`。
- **正式签名**：现在的 release 包用的是 debug 密钥。换成正式密钥后，需要先卸载旧包再安装（签名不同，系统不允许直接覆盖）。卸载前文档都在 `Documents/momoda`，不会丢。
- 发布相关的完整清单，见发布准备会话的 `docs/RELEASE.md`（在它自己的分支上）。
