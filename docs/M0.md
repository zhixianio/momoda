# M0 验证

M0 原型只用来回答一个问题：**在 N10 Pro 2 上，用蓝牙键盘加中文输入法，能不能舒服地打字？** 它不是产品，界面也是临时的。

## 模拟器上已经验证（2026-10-19）

环境：Android 14 模拟器（1404×1872），fcitx5-android 0.1.3 拼音输入法，通过 `adb input` 模拟实体键盘。

| 项目 | 结果 |
|---|---|
| 冷启动 | 约 70–90ms 进入编辑器（`am start -W` 测得 TotalTime 218ms） |
| 26MB 字体加载 | 约 2ms（字体不压缩打包，可以直接 mmap） |
| 实体键盘 + fcitx5 拼音 | ✅ 候选框正常，空格上屏 |
| `Ctrl+Space` 切换中英文 | ✅ 透传给输入法 |
| 中文状态下按 `Ctrl+B` / `Ctrl+1` | ✅ 被 App 截获并执行，输入法没有吞掉 |
| 拼写中按 `Ctrl+1` | ⚠️ 快捷键生效，但拼写到一半的拼音会被丢弃 |
| 拼写中按 Esc | ✅ 输入法取消拼写，App 不退出 |
| 空闲时按 Esc | ✅ 被 App 吞掉，不会触发“返回”退出 App |
| vim normal 模式（输入法处于拼音状态） | ✅ `hjkl x gg dd G o` 全部被 App 截获，没有进入输入法 |
| 上屏后按 Esc 进入 normal | ⚠️ 要按两次，第一次被 fcitx5 用来关闭联想候选 |
| `Ctrl+End` 等编辑键 | ✅ 走系统默认行为 |
| 避头尾 | ✅ 句号、逗号、右括号没有出现在行首 |
| 中文引号 | ⚠️ 霞鹜文楷屏幕阅读版的“”是半角宽度，M2 再处理 |

## 第一轮真机试用反馈（Realforce USB 键盘 + 汉王输入法）

| 反馈 | 原因 | 处理 |
|---|---|---|
| 系统刷新模式调成“极速”后体验很好 | — | 记下来：设计 v1 的刷新优化时，以“极速”模式作为基准 |
| 汉王输入法偏弱，想要支持小鹤双拼、适合墨水屏的输入法 | — | 推荐 fcitx5-android（见下） |
| 命令面板切换选中项时有拖沓的动画 | AlertDialog 的选中态带水波纹和渐变，背景还有压暗 | 换成自绘的 `InkList`：静态黑框、无压暗、无窗口动画 ✅ |
| vim 模式下 Esc 切不到 normal | 汉王输入法吞掉所有 Esc，App 永远等不到输入法“放行” | insert 模式下 Esc 立即切到 normal，同时把 Esc 交给输入法收起候选，再重置输入法状态。fcitx5 和汉王输入法都验证通过 ✅ |
| 光标丢失两次，“字不知道去哪了” | 文件内容完整，推测是光标走到屏幕底部，被输入法候选栏挡住；关闭弹窗后输入法没有重新连接到编辑器也可能造成 | 改为翻半页滚动：光标接近底部时，一次把它推到屏幕上部 1/4 处，底部留 1/3 屏空白；关闭弹窗后主动重连输入法 ⏳ 需要再试一次确认 |

### 输入法：fcitx5-android
- 开源，GitHub `fcitx5-android/fcitx5-android`。拼音引擎自带**双拼，可选小鹤方案**。
- 实体键盘支持好：在模拟器上验证过拼音输入、`Ctrl+Space` 切换中英文、App 快捷键和 vim 都正常。
- 有联想候选；如果觉得 Esc 被它占用，可以在设置里关掉联想（墨墨打的 vim 模式已经不受影响）。

## 需要你在真机上验证

### 准备
1. **开启开发者选项**：设置 → 关于设备 → 连点“版本号”7 次 → 回到设置，找到“开发者选项”→ 开启“USB 调试”。如果找不到，告诉我，这一步决定了我能不能直接调试真机。
2. **安装中文输入法**，任选一款支持实体键盘的：
   - **fcitx5-android**（模拟器上已经验证过）：在 GitHub `fcitx5-android/fcitx5-android` 的 Releases 下载 arm64-v8a 版本。
   - 同文输入法 Trime，或者讯飞、搜狗。
3. **连接蓝牙键盘**，确认系统“显示虚拟键盘”处于关闭状态。
4. **用 USB 连接 Mac**，由我安装 APK。如果开不了 USB 调试，我把 APK 发给你，你手动安装。

### 检查清单
- [ ] 能否打开开发者选项，`adb devices` 能否看到设备
- [ ] 蓝牙键盘配合中文输入法能否正常打字，候选框显示在哪里，墨水屏上是否看得清
- [ ] 打开调试面板（`Ctrl+Shift+D`），记下“按键→重绘”的延迟数值，以及**主观感受**：跟手吗？有拖影吗？
- [ ] `Ctrl+N` / `Ctrl+O` / `Ctrl+K` / `Ctrl+B` / `Ctrl+1` / `Ctrl+.` / `Ctrl+=` 在中文状态下是否都能生效
- [ ] `Ctrl+Z` 能否撤销
- [ ] Esc 会不会退出 App
- [ ] 开启 vim（`Ctrl+Shift+V`），按 Esc 进入 NORMAL（状态栏会显示），`hjkl` 能否移动光标、有没有变成拼音
- [ ] 霞鹜文楷在墨水屏上的观感：笔画粗细、字号 20 是否合适、行距是否舒服
- [ ] 光标闪烁是否导致屏幕频繁刷新（模拟器上看不出来）
- [ ] 用 USB 连接 Mac 后，在 `Android/data/app.momoda/files/docs/` 能否看到 `.md` 文件（macOS 需要用 Android File Transfer 或 OpenMTP）
- [ ] 写到一半强制关闭 App（最近任务里划掉），重新打开后有没有丢字

## M0 原型的操作说明

| 按键 | 作用 |
|---|---|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+K` | 新建文档 / 文档列表 / 命令列表（用笔：点右下角「⋯」或状态栏） |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+1..3` / `Ctrl+0` | 粗体 / 斜体 / 标题 / 恢复正文 |
| `Ctrl+.` | zen 模式（隐藏状态栏和系统栏） |
| `Ctrl+=` / `Ctrl+-` | 字号 |
| `Ctrl+S` | 立即保存（平时会自动保存） |
| `Ctrl+Shift+D` | 调试面板：当前输入法、延迟、按键去向、文件路径 |
| `Ctrl+Shift+V` | vim 模式开关 |
