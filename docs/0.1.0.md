# 0.1.0 发布：需求冻结与清单

**2026-10-20 起冻结 0.1.0 的需求。** 范围就是 `CHANGELOG.md` 里 `[0.1.0]` 这一节列出的功能，不再加新功能。

## 冻结期间可以合进 main 的改动

- 修 bug：发布前测试（Android 8/10/12、升级路径、数据量）或汉王上实际使用中发现的问题。会丢字、崩溃、泄露凭证的问题必须修；其他问题看风险，拿不准的推迟到 0.1.1。
- 文档和发布说明：CHANGELOG、README、官网、本文件。
- 每个修复都要附测试，`./gradlew testDebugUnitTest assembleRelease` 必须通过。

其他改动一律推迟到 0.1.0 发布之后。例外（新用户的第一印象，改动小，经确认放进 0.1.0）：第一次打开时的欢迎文档；命令面板固定分组和“常用”；页脚靠左；设置底部精简；“从其他设备粘贴”改名并在 AI、同步设置里加入口；实体键盘布局（CapsLock 当 Ctrl、互换）；专注模式默认关闭，切换模式时提示；翻页方式设置（默认连续）。

## 推迟到 0.1.0 之后

- `_agent/` 文件的并排查看（Ctrl+Shift+A）
- 子目录里的文档出现在文档列表和管理页
- 完整的 vim（选择、复制粘贴、合并行等）
- 打字机模式、ADHD 连击条等实验
- 同步的进度显示
- 保存改到后台线程（先看真机上的诊断记录：保存超过 1 秒会记一条）
- “接收测试版”开关（目前所有版本都不带 `-`，以普通版本发布）
- 给 GitHub App 上传 logo
