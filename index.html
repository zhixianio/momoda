## 为墨水屏而做

光标常亮不闪，写满一页时整页翻过，从不滚动，打字时屏幕上只有新字出现。专注模式下只有当前段落是黑色，Ctrl . 隐藏页眉页脚。中文排版细节也照顾到了：标点避头尾，引号用全角字形，内置霞鹜文楷，也可以把自己的 .ttf / .otf 放进 Documents/momoda/fonts。

## 所见即所得的 Markdown

标题、粗体、斜体、引用、列表、分隔线边写边渲染。#、** 这些标记留在原处、只是变浅，光标移动时排版不会跳。文件就是标准的 .md，换任何编辑器都能打开。

## 全键盘操作

不用鼠标，也不用触控。常用操作都有快捷键，其余都在 Ctrl K 命令面板里，命令和文档都支持拼音首字母：输入 tb 就是“立即同步”。中文输入法打开时，快捷键也不会被吞掉。

## Vim 键位

Ctrl Shift V 打开 Vim 模式：hjkl、w b、0 $、gg G、x、dd、u、Ctrl R，以及 i a A I o O。不管用哪个输入法，Esc 都能立刻回到普通模式。

## CapsLock 换 Ctrl

墨墨打自带两个实体键盘布局：“CapsLock 当 Ctrl”和“CapsLock 与 Ctrl 互换”，在系统设置的实体键盘里选用，所有 App 里都生效。

## GitHub 同步

文档都是 Documents/momoda 里的 .md 文件，卸载应用也不会删除。可选同步到自己的 GitHub 仓库：在手机或电脑上输入屏幕上的验证码即可登录，不用在墨水屏上打 token。两端同时修改时，两个版本都会保留。

## 可选的 AI 助手

默认关闭。需要时填一个 OpenAI 兼容的接口，包括本地的 Ollama：润色、续写、精简、翻译，也可以写自己的指令。结果确认后才写入正文。
