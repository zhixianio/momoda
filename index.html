## 为中文优化

标点避头尾，中文引号使用全角字形，内置霞鹜文楷。字数按汉字和英文单词统计。命令和文档支持拼音首字母搜索。推荐搭配 fcitx5 与小鹤双拼。

## 极简专注

界面只有正文。光标常亮不闪，写满一页时整页翻过，不滚动。专注模式下只有当前段落为黑色；Ctrl . 隐藏页眉页脚。

## 全键盘操作

所有功能都能用键盘完成：常用操作有快捷键，其余都在 Ctrl K 命令面板里。可选 Vim 模式，支持常用的移动、删除和撤销。

## 存储与同步

文档以 .md 文件保存在 Documents/momoda，首行即标题，卸载应用不会删除。可选 GitHub 同步，在手机或电脑上输入验证码即可登录；两端同时修改时，两个版本都会保留。

## AI 助手

支持任何 OpenAI 兼容接口，包括本地的 Ollama。润色、续写、精简、翻译，也可以自定义指令。结果确认后才写入正文。

## 开源与隐私

以 GPL-3.0 开源。不需要账号，不收集任何数据。API key 和 GitHub 凭证只保存在本机。
