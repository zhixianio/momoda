# 欢迎使用墨墨打

## 操作

- Ctrl+K 打开命令面板，所有功能都在里面，可以用拼音首字母搜
- 也可以直接点击右下角的「⋯」
- Ctrl+N 新建，Ctrl+O 切换文档
- Ctrl+. Zen 模式（隐藏页眉页脚），Ctrl+Shift+F 专注模式（只突出当前段落）
- Ctrl+Shift+V Vim 模式：Esc 普通模式，hjkl 移动，i 输入

## 写作

- 第一行是标题，也是文件名
- 回车分段，Shift+回车换行
- 自动保存，文档都在 Documents/momoda/ 里

## 一个建议

在系统设置里把墨水屏的刷新模式调到最快的一档，打字会更跟手。

读完可以删掉这篇：Ctrl+K，输入 sc，选“删除当前文档”。
